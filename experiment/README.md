# Benchmark links

This directory records benchmark sources used in the DIFCVerilog experiments.
It does not redistribute third-party benchmark RTL. Download the datasets from
their original sources, then place or convert them locally as needed.

## Dataset sources

| Dataset | Public source |
|---|---|
| Hack@DAC 2018 | <https://github.com/HACK-EVENT/hackatdac18> |
| Hack@DAC 2019 | <https://github.com/HACK-EVENT/hackatdac19> |
| Hack@DAC 2021 | <https://github.com/HACK-EVENT/hackatdac21> |
| GHOST benchmarks | <https://github.com/HSTRG1/GHOST_benchmarks> |
| TrustHub AES and BasicRSA Trojan benchmarks | TrustHub benchmark family; see `SOURCES.md` |
| OpenCores DES/3DES | <https://opencores.org/projects/des> |
| OpenCores SHA cores | <https://opencores.org/projects/sha_core> |

Each dataset keeps its original license. Do not apply the DIFCVerilog license
to third-party benchmark code.

## Reproducing experiments

Full benchmark copies, converted Verilog files, labels, and generated outputs
should be kept in a local workspace or in a separate artifact package with
complete license and source records.
